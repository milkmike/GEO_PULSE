# Гибридное раскрытие причин сигнала — дизайн

## Задача

Карточка сигнала сейчас сообщает только факт статистического сдвига. Пользователь
видит страну, важность и показатели, но не получает новостного контекста и не
понимает, куда перейти за разбором.

## Утверждённый интерфейс

Карточка остаётся компактной, но получает блок с двумя публикациями и отдельную
кнопку `Разобрать причины и источники →`.

- Для детекторов, сохранивших `article_ids`, карточка показывает две публикации,
  на которых непосредственно основан сигнал.
- Для агрегатных детекторов без `article_ids`, включая `tone_shift`, карточка
  показывает две наиболее значимые релевантные публикации источников этой страны
  за 72 часа до срабатывания. Блок называется `Что происходило в момент сдвига`:
  это контекст для расследования, а не заявление о доказанной причинности.
- Каждая публикация содержит заголовок, источник, дату и безопасную прямую ссылку.
- Карточка больше не является одной большой ссылкой: ссылки публикаций открывают
  первоисточники, а отдельная кнопка ведёт на `/signals/{id}`.
- Если публикаций нет, интерфейс честно сообщает, что контекст не найден, и всё
  равно позволяет открыть сохранённые значения и правило детектора.

## Глубокий разбор

Существующая страница `/signals/{id}` остаётся основной точкой расследования. Она
показывает правило, наблюдаемое значение, базовую линию, окно, график и точные
публикации-доказательства. Для агрегатных сигналов без точных публикаций она
дополнительно показывает `Новостной контекст` с тем же предупреждением об
отсутствии доказанной причинной связи.

## Данные и производительность

Список сигналов загружает превью пакетно, без отдельного запроса на каждую
карточку. Сначала используются сохранённые `signal_evidence.article_ids`; только
при их отсутствии выбираются контекстные статьи страны. На сигнал возвращается
не больше двух записей.

Все новые операции только читают существующие `signals`, `signal_evidence`,
`articles`, `analysis` и `sources`. Миграций, удаления, пересчёта и перезаписи
собранных статей или исторических значений термометра нет.

## Деплой

После тестов включается существующий `FEATURE_SIGNAL_DETAIL=true`. Обновляются
только API и web-контейнеры; база данных и фоновые сборщики не пересоздаются.
После выкладки проверяются главная, `/signals`, одна карточка `tone_shift`, её
страница разбора и прямые ссылки на публикации.
